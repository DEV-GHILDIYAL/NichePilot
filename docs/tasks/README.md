# Task records

Create a short file in `docs/tasks/active/` only when work spans several decisions or sessions and future continuation would otherwise require reconstructing context. Include objective, scope, affected modules/docs, constraints, chosen implementation, validation, status, and next action. Move it to `completed/` when finished; completed records are historical and never required reading for routine work. Do not create placeholders or task records for trivial changes. The [development workflow](../development/workflow.md) is the general process.
