# NichePilot

NichePilot is a planned autonomous AI social-media creator platform. Its first target is one Instagram account with a durable niche and an administrator dashboard. It will discover relevant trends, make content, evaluate it, publish through supported APIs when enabled, and learn from performance within that niche.

**Status:** Phase 1 backend foundation. Account and Niche DNA APIs are implemented; no frontend, autonomous workflow, external integration, or live publishing exists.
